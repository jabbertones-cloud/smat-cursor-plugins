# Amazon seller evidence triage

1. Identify account, marketplace, dates, SKU, ASIN and FNSKU before joining records. Keep unrelated product identifiers separate.
2. Use only reports, exports, notes and records the user has authorized in the current workspace. Do not request Amazon credentials.
3. Separate inventory categories: inbound, reserved, fulfillable, unfulfillable, damaged, returned and unresolved.
4. Separate reported facts from derived calculations and missing coverage. Label each finding observed, derived, pending or unknown.
5. Avoid inferring cause of sales drops from one report. Compare matched periods and check data completeness, listing state, traffic and availability.
6. Cite exact filename, page, sheet or row for each conclusion. Do not infer ASIN impact from unrelated case mentions.
7. Return a ranked investigation queue with next safe read and the evidence needed. No live SP-API access or seller-account edits are included.
