# AiSCent for Cursor

Free Xcode localization, screenshot and release-readiness audits using local project files.

The two included skills are **free, local-file workflows**. Open your own authorized repository, CSV or public record in Cursor and ask for a skill by name. Neither plugin nor its skills require an SMAT account, subscription, trial or payment.

This Cursor package intentionally does not include the commercial hosted MCP, API calls, CLI scripts, credentials, account permissions, server-side operations or any telemetry. It does not transmit local records to SMAT. This is an independent free companion, **not** the product's live integration or paid feature set.
